Study Techniques

01

Retrieval Practice

Close your notes and bring information back from memory before checking the answer.

02

Spaced Practice

Return to material across several sessions instead of doing one giant cram session.

03

Interleaving

Mix different types of problems so you have to decide which method each problem needs.

04

Feynman Check

Explain an idea simply, find the gaps, then return to your source and repair them.

05

Elaboration

Ask why, how, and what is an example to connect new information with what you know.

06

Dual Coding

Combine words with a useful diagram, timeline, table, flowchart, or concept map.
